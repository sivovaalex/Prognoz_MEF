# КФ «Рейтинг ОМСУ» — прототип

Прототип доработки ИС «Конструктор форм» (ГАС «Управление» МО) — модуль формирования рейтинга муниципальных образований Московской области.

## Возможности

- Ролевая модель: Администратор КФ, МЭФ (куратор/согласующий), отраслевой ЦИО, ОМСУ
- Настройка показателей, формул, весов и привязки к отраслевым ЦИО
- Запуск сбора данных с контрольными сроками, автоматическая рассылка уведомлений
- Заполнение показателей ОМСУ, подписание ЭЦП, отправка на согласование ЦИО, отзыв на изменение
- Согласование показателей ОМСУ отраслевым ЦИО (блокировка после согласования)
- Внесение ЦИО собственных значений по тем же показателям (со справочным средним по ОМСУ), ЭЦП, согласование МЭФ
- Сводный рейтинг: по территории / по направлению / по показателям / сравнение вариантов расчёта
- Режимы «предварительный» (все введённые данные) и «итоговый» (только согласованные)

## Стек

React 19 + TypeScript + Vite + Tailwind CSS 3.4 + shadcn/ui

## Запуск

```bash
npm install
npm run dev     # дев-сервер
npm run build   # продакшн-сборка в dist/
```

Данные демонстрационные, хранятся в памяти браузера (без бэкенда).
